# 🎨 Иконки для Android

Положите в эту папку следующие файлы:

## Обязательные файлы

### icon.png
- **Размер:** 512x512 пикселей
- **Формат:** PNG
- **Назначение:** Основная иконка для Google Play

### icon_foreground.png
- **Размер:** 512x512 пикселей
- **Формат:** PNG с прозрачным фоном
- **Назначение:** Передний план адаптивной иконки

### icon_background.png
- **Размер:** 512x512 пикселей
- **Формат:** PNG
- **Назначение:** Фон адаптивной иконки

## Как создать адаптивные иконки

### Способ 1: Android Asset Studio (рекомендуется)
1. Откройте https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html
2. Выберите "Image" в разделе Foreground
3. Загрузите ваше изображение
4. Настройте фон (Background)
5. Скачайте ZIP архив
6. Извлеките файлы:
   - `res/mipmap-hdpi/ic_launcher_foreground.png` → `icon_foreground.png`
   - `res/mipmap-hdpi/ic_launcher_background.png` → `icon_background.png`

### Способ 2: Вручную
1. Создайте изображение 512x512 для фона (цвет #4F46E5)
2. Создайте изображение 512x512 для переднего плана (логотип)
3. Сохраните как PNG

## Рекомендации к дизайну

### Передний план (Foreground)
- Логотип V-Message (💬 или буква "V")
- Размер основного элемента: ~300x300 px по центру
- Прозрачный фон
- Контрастные цвета

### Фон (Background)
- Сплошной цвет: #4F46E5 (индиго)
- Или градиент
- Без текста

## Адаптивные иконки Android

Начиная с Android 8.0, используются адаптивные иконки:

- **Foreground:** передний план (логотип)
- **Background:** фон (цвет или градиент)

Система автоматически применяет маску (круг, квадрат, капля) в зависимости от темы устройства.

## Проверка иконки

После сборки проверьте:
- [ ] Иконка отображается в лаунчере
- [ ] Иконка в настройках приложения
- [ ] Иконка в списке приложений
- [ ] Адаптивная иконка обрезается корректно

## Google Play требования

- **Размер:** 512x512 px
- **Формат:** 32-bit PNG
- **Фон:** прозрачный или сплошной цвет
- **Без текста:** не рекомендуется текст на иконке
