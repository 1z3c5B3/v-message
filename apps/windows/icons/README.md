# 🎨 Иконки для Windows

Положите в эту папку следующие файлы:

## Обязательные файлы

### icon.ico
- **Размер:** 256x256 пикселей (минимум)
- **Формат:** ICO
- **Назначение:** Основная иконка приложения

### icon.png
- **Размер:** 256x256 пикселей
- **Формат:** PNG с прозрачным фоном
- **Назначение:** Для установщика и ресурсов

## Как создать иконку

### Способ 1: Онлайн конвертер
1. Откройте https://convertio.co/png-ico/
2. Загрузите PNG 512x512
3. Скачайте ICO
4. Переименуйте в `icon.ico`

### Способ 2: GIMP (бесплатно)
1. Откройте ваше изображение 512x512
2. Файл → Экспортировать как...
3. Выберите формат .ico
4. В настройках выберите размеры: 256x256, 128x128, 64x64, 48x48, 32x32, 16x16

### Способ 3: Photoshop
1. Откройте изображение 512x512
2. Изображение → Размер изображения → 256x256
3. Файл → Сохранить как → ICO

## Рекомендации к дизайну

- Используйте логотип V-Message (💬 или текст "V")
- Фон: прозрачный или цвет #4F46E5
- Минимум деталей (иконка маленькая)
- Контрастные цвета

## Пример структуры ICO файла

```
icon.ico содержит:
  - 256x256 px (для больших экранов)
  - 128x128 px
  - 64x64 px
  - 48x48 px (для панели задач)
  - 32x32 px
  - 16x16 px (для заголовка окна)
```
